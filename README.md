# 5.0 Духовный подъём

Регистрация на пятый осенний выезд молодёжи церкви «Источник Пробуждения».

- Настройки (название, даты, цена, WhatsApp-группа, адрес Google Apps Script): `src/config.js`
- Запуск локально: `npm install && npm run dev`
- Деплой: каждый push в `main` собирает сайт и выкладывает на GitHub Pages
